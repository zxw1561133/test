# UAV轨迹可视化工具

这是一个用于可视化无人机（UAV）轨迹和风险信息的工具集合。该工具基于Python和Matplotlib实现，提供了3D和2D视图来展示无人机的飞行轨迹、风险信息和相关数据。

## 主要功能

- 3D轨迹可视化：显示多架无人机的飞行路径
- 风险信息显示：可视化碰撞风险、风险区域等安全信息
- 实时动画：通过动画方式展示无人机运动
- 放大视图：支持对特定区域或无人机的详细观察
- 交互控制：提供播放、暂停、步进等交互功能

## 主要文件

- `platform_display.py`：主要的可视化程序，包含下拉菜单和完整的3D显示功能
- `plot.py`：基础绘图功能
- 数据目录：`plugin_data/`包含各种CSV格式的无人机轨迹和风险数据

## 使用方法

1. 确保已安装必要的Python库：numpy, matplotlib, pandas
2. 运行主程序：`python platform_display.py`
3. 使用界面上的控制按钮调整视图和播放设置
